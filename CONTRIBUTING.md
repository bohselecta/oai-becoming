# Contributing

Start with `AGENTS.md` and `docs/ARCHITECTURE.md`. Preserve comparative placement as the product's purpose and evidence integrity as its measurement contract. Use a branch and a focused pull request. Include a reproduction for defects and a test for any changed invariant.

Run `npm run check` and the browser suite before requesting review. Describe which checks actually ran and include rendered desktop/mobile evidence for interface changes. Do not add runtime dependencies, paid services, tracking or real participant data without an explicit design review.

Keep examples synthetic and label them. Never include private chats, credentials, real assessment records or third-party personal profiles in issues, fixtures or screenshots. For a potential security defect, do not publish sensitive exploit data in an issue; contact the repository owner through an established private channel.
